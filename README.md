## Atividade Threads para Processos Paralelos

# Para analisar o código: 
Baixar o .zip do projeto, descomprimir e rodar utilizando VS Code (ou IDE similar).

# Para executar o programa direto:
- Entre na pasta do projeto

- Linux
```bash
# Compilar e executar
javac --release 17 -d out src/*.java
```

- Windows (PowerShell / CMD)

```bat
:: Compilar
javac -d out src\*.java

:: Executar
java -cp out Main
```
